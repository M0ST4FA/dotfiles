# Flame theme provenance

The animation frames and GPL-3.0 license come from the `flame` theme in
[`adi1090x/plymouth-themes`](https://github.com/adi1090x/plymouth-themes),
commit `5d8817458d764bff4ff9daae94cf1bbaabf16ede`.

The Plymouth script and dialog assets are local adaptations. They retain the
upstream animation while adding the Catppuccin Frappé unlock dialog.
